    Corrections and reference methods¶

    DISP displacement is relative in space and in time. In time, each granule is relative to its ministack's reference date, until chain chains them. In space, values are relative to an arbitrary point, so a map means something only after re-referencing. The order follows the product:

    1. correct: subtract correction layers, per granule (they are relative to each granule's reference date, so this comes before chaining);
    2. mask (optional);
    3. chain: chain the ministacks;
    4. rereference: choose what is zero in each epoch.

    The synthetic frame has a low-coherence corner, a patch where unwrapping failed, water columns on the east edge and a few persistent scatterers, so the methods can be compared.

    Corrections¶

    correct subtracts the product's ionospheric delay and solid-earth tide ("product" in the command line picks those the product has not applied already). External corrections, such as a troposphere model, go in external= on the same grid.

    corrected = dxr.correct(raw, ["ionospheric_delay", "solid_earth_tide"])
change = (corrected.displacement - raw.displacement).isel(time=-1).mean().values
print(f"correction at the last epoch: {1e3 * float(change):+.1f} mm")
ds = dxr.chain(dxr.mask(corrected, "recommended"))

    Reference methods¶

    Method Zero in each epoch Use when
    point one pixel (row/col, lon/lat) a GNSS station, a stable point
    area median of a lon/lat box or polygon a stable region (robust)
    median median of the scene's good pixels the scene is mostly stable
    border median of a border strip deformation sits in the middle
    high_coherence median of a good-pixel mask you have your own mask
    auto a stable pixel chosen from the quality layers no prior knowledge

    auto picks a pixel that is never masked, has no phase jumps, and has high harmonic-mean coherence, close to the middle of the good area. It prefers persistent scatterers. It reads every quality layer of every epoch first, which is slow on full frames (see "Large frames and batch jobs").

    The maps differ only by a constant in each epoch: re-referencing never changes the relative motion between two pixels. What changes is which part of the frame reads as zero, and how much noise the reference carries into every pixel. A single pixel carries its own noise; a median over many good pixels averages it down. Here auto chose pixel (30, 30), one of the frame's persistent scatterers.
