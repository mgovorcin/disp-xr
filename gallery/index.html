    Tutorials¶

    Each tutorial is a short, executed example. Most run on a synthetic frame from disp_xr.tutorial, so they work anywhere and are re-run every time the documentation builds; a broken example fails the build. Replace the synthetic folder with your own granules to run them on real data.

    Basics¶

    • Quick look at a frame

      Open, chain, re-reference, plot a map and a time series.

    • The command line, end to end

      info, stack and export without writing Python.

    • Exporting results

      Zarr, NetCDF, GeoTIFF, MintPy and pyramids.

    • Chunks for maps and time series

      Pick the layout for the reads you do most.

    Quality and references¶

    • Quality layers and masking

      The recommended mask, presets and per-criterion masks.

    • Quality weights

      Down-weight instead of mask: similarity, coherence, residual cycles.

    • Corrections and reference methods

      The processing order and all six reference methods compared.

    • Line-of-sight geometry and plate motion

      Static layers, ENU to LOS, ITRF2014 plate-motion removal.

    Time series¶

    • Velocity from a trajectory fit

      Offset, velocity, seasonal terms and steps for every pixel.

    • Velocity with colored-noise uncertainty

      OLS, Whittle, MIDAS and GLS sigmas side by side.

    • Checking a velocity fit

      Residual autocorrelation, normality and significance.

    • Denoising and regular time grids

      Kalman and LOWESS, regular grids, refused gaps, declared breaks.

    Downsampling¶

    • Downsampling with quality weights

      Regular grids, hexagons and quadtrees with correlated-error sigmas.

    GNSS¶

    • Comparing DISP with GNSS

      Station velocities, pairwise RMSE and the OPERA requirements.

    • Tying DISP to GNSS

      Remove long-wavelength error with a fitted plane, checked by cross-validation.

    Real data¶

    Run on production granules; the saved outputs are shown and the build does not run them again.

    • Comparing two processing versions

      Frame F08622 (New York City): the same 239 acquisitions as product version 1.0 and 1.1, on common epochs and reference.

    Cloud and serving¶

    • Virtual frames and versioned stores

      Icechunk: reference granules in place, commit, time travel, tag.

    • Serving results as web map tiles

      xpublish-tiles behind MapLibre or Leaflet.

    • A REST service for web clients

      disp_xr serve: point series, velocity, cells as GeoJSON, GNSS residuals, provenance.

    • Interactive browsing of a full frame

      hvplot and datashader on a lazy stack.
