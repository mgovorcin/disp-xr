    Serving results as web map tiles¶

    xpublish-tiles serves xarray datasets as OGC Tiles for any web map (MapLibre, Leaflet, QGIS): PNG tiles rendered on request from the data, a TileJSON description and a legend. A velocity map, a displacement epoch or a quality layer from disp-xr can go straight in. A Zarr or GeoZarr store from to_zarr or to_geozarr works too, with multiscale pyramids picked by zoom level.

    This page fits a velocity on a synthetic frame, starts a local server and fetches a tile and the legend. In a real deployment the server runs behind your web map (see the end).

    Serve¶

    xpublish.Rest serves named datasets; TilesPlugin adds the tile endpoints under /datasets/<name>/tiles/.

    On a web map¶

    Point a raster source at the tile URL template. With MapLibre GL JS:

    map.addSource("velocity", {
  "type": "raster",
  tiles: ["https://your-server/datasets/velocity/tiles/WebMercatorQuad/{z}/{y}/{x}"
          + "?variables=velocity&style=raster/RdBu&colorscalerange=-30,30"
          + "&width=256&height=256"],
  tileSize: 256,
});
map.addLayer({ id: "velocity", type: "raster", source: "velocity" });

    {base}/tilejson.json with the same parameters describes the layer (bounds, zooms) for clients that read TileJSON. To serve a whole frame, open its store lazily (xr.open_zarr, or a pyramid from to_geozarr): tiles read only the chunks they cover.
