# Plot

These need the `plot` extra (`pip install "disp_xr[plot]"`). The functions
live in `disp_xr.plot` and are methods of the [accessor](accessor.md):
`ds.disp.plot_map()`, `ds.disp.plot_point(lon, lat)`.
